# pop'n music リザルト整形ツール

e-amusementアプリのプレーシェア機能で表示された、pop'n musicのゲームリザルト画面のスクリーンショットを、SNS投稿しやすい形に加工するための静的Webアプリです。すべての画像処理はブラウザ内で完結し、画像が外部サーバーに送信されることはありません。

## 機能
- スクリーンショットに写り込むスマホの上部メニューなど機種依存の余白を、自動検出してトリミング
- オプションで、判定内訳の一部(BAD・COMBOなど)の位置を移動して見やすく並べ替え
- オプションでプレイ日付・ユーザー名を非表示化
- 複数枚のリザルトを1枚に集約

## 余白の自動トリミングについて
機種・スクリーンショットの撮り方によっては本体を正しく検出できない場合があります。

## マスク位置の調整(開発者向け)
プレイ日付・ユーザー名マスクの矩形位置(`js/layoutConfig.js` の `regions`)は、`mask-editor.html` を開くとプレビュー画像上でドラッグ&リサイズしながら調整できます。調整後に表示されるコードを `layoutConfig.js` に貼り付けてください。一般利用者向けの機能ではないため、サイトの導線からはリンクしていません。

## その他
サイトの利用状況を把握して将来の改善に役立てるため、Google Analyticsを利用しています。
